# 使用指南

## 一、环境准备

| 工具 | 用途 | 获取方式 |
| --- | --- | --- |
| Python 3.8+ | 运行剥离脚本 | https://www.python.org/downloads/ |
| JDK 17 | apktool / apksigner 依赖 | https://adoptium.net/ |
| apktool ≥ 2.9 | 解包与回包 | https://ibotpeaches.github.io/Apktool/ |
| Build-Tools | `apksigner` / `zipalign` | Android SDK Manager 安装 |

验证：

```bash
python --version
apktool --version
apksigner --version
```

## 二、扫描 APK

```bash
# 单个
python tools/apk_ad_strip.py --list ~/downloads/vivo-browser.apk

# 批量（脚本）
bash scripts/scan_ads.sh ~/downloads/
```

输出分两档：

- **高置信度**：包名前缀命中、继承已知广告基类、布局中引用广告控件 —— 可直接剥离。
- **待确认**：短类名含 `ad`、资源文件名疑似 —— 需要人工看上下文，用 `--confidence medium` 才会一并移除。

## 三、剥离与签名

```bash
python tools/apk_ad_strip.py --strip --apk ~/downloads/app.apk -o out/
```

生成 `out/app-noads.apk`。

**签名**（不签名无法直接安装）：

```bash
# 方式一：工具内置（使用 debug keystore）
python tools/apk_ad_strip.py --strip --apk app.apk -o out/ --sign

# 方式二：手动
zipalign -f -p 4 out/app-noads.apk out/app-aligned.apk
apksigner sign --ks ~/.android/debug.keystore --out out/app-signed.apk out/app-aligned.apk
```

debug keystore 不存在时生成：

```bash
keytool -genkey -v -keystore ~/.android/debug.keystore \
  -storepass android -alias androiddebugkey -keypass android \
  -keyalg RSA -keysize 2048 -validity 10000
```

## 四、Magisk 模块

```bash
bash scripts/build_module.sh
```

产物 `dist/vivo-remove-ads-v1.0.0.zip`，刷入 Magisk / KernelSU / APatch 后重启。

模块做两件事：

1. 写入 `/data/adblock/hosts`，屏蔽主流广告域名。
2. 开机时 `pm disable-user` 禁用匹配到的广告包，并结束残留广告进程。

## 五、常见回滚

```bash
# 解除域名屏蔽
rm -f /data/adblock/hosts

# 重新启用被禁用的包
pm enable com.qq.e.ads
pm enable <包名>
```

## 六、注意事项

- 剥离后应用可能因完整性校验而无法启动；这类应用请用 `--confidence high` 最小化改动。
- 厂商 ROM 版本更新后广告包名会变，重新跑一次 `--list` 更新规则表即可。
- 部分场景下广告由服务端下发配置决定，客户端剥离无效，需结合抓包定位。
